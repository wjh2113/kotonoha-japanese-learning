# 【课文整理】第009课

整理自本课讲义（结构文件＋图片转写＋文字版）：电器店会话两篇。每篇逐行对照中文解释，并附语法考点。

## 课文1：电器店问路（会話①）

学习目标：店の人に　商品（しょうひん）の場所（ばしょ）や　値段（ねだん）を　聞いて、答え（こたえ）を　理解（りかい）する　ことができる。（能向店员询问商品的位置和价格，并理解回答。）

| 原文 | 中文解释 |
| --- | --- |
| 店員：いらっしゃいませ。 | 店员：欢迎光临。（进店时的迎客固定用语） |
| リン：すみません。電子辞書、ありますか。 | 林：劳驾。有电子词典吗？（すみません：搭话、致歉；ありますか：有……吗） |
| 店員：はい、ございます。 | 店员：是的，有。（ございます＝あります 的礼貌说法） |
| リン：どこですか。 | 林：在哪里？（どこ：疑问词，哪里） |
| 店員：あちらです。どうぞ。 | 店员：在那边，请。（あちら：那边的礼貌说法；どうぞ：请） |

插图：家电卖场（家電 1F 2F 的楼层指示牌），顾客向店员问路。

**语法考点**

- 句型「～（は）ありますか」：询问某物是否存在。文中例句：電子辞書、ありますか。说明：助词は可省略，句尾か表示疑问。
- 惯用「はい、ございます」：肯定回答“有”。文中例句：はい、ございます。说明：ございます 是 あります 的礼貌表达，服务行业常用。
- 疑问词「どこ」＋ですか：询问地点。文中例句：どこですか。说明：どこ（哪里）是本课疑问词表的核心词。

## 课文2：询问价格与购买（会話②）

学习目标：能够向店员询问商品，并能请店员帮助寻找其他商品。

| 原文 | 中文解释 |
| --- | --- |
| 店員：こちらは　いかがですか。新しい　電子辞書です。 | 店员：这个怎么样？是新款电子词典。（いかが＝どう 的礼貌说法；こちら：这个的礼貌说法） |
| リン：日本のですか。 | 林：是日本（制造）的吗？（の 代替名词，指“日本货”） |
| 店員：はい、カシオのです。23,800円です。 | 店员：是的，是卡西欧的。23,800日元。（円：日元） |
| リン：もっと　安いの、ありませんか。 | 林：有更便宜的吗？（もっと：更加；の 代替“电子词典”） |
| 店員：はい。こちらは　18,500円です。 | 店员：有的。这个是18,500日元。 |
| リン：ケースは　いくらですか。 | 林：外壳多少钱？（いくら：疑问词，多少钱） |
| 店員：1,500円です。 | 店员：1,500日元。 |
| リン：じゃあ、この　電子辞書と　ケースを　ください。 | 林：那么，请给我这个电子词典和外壳。（じゃあ：那么；～をください：请给我……） |
| 店員：ありがとうございます。 | 店员：谢谢（惠顾）。 |

插图：店员向顾客介绍货架上的電子辞書（标价 ¥23,800／¥18,500）和ケース。

**语法考点**

- 句型「～は いかがですか」：礼貌地询问“……怎么样”。文中例句：こちらはいかがですか。说明：いかが 是 どう 的礼貌说法，店员推荐商品时常用。
- 句型「～は いくらですか」：询问价格。文中例句：ケースはいくらですか。说明：いくら（多少钱）是本课疑问词表的核心词。
- 句型「～を ください」：请给我……。文中例句：この電子辞書とケースをください。说明：购物、点餐的固定表达；と 连接两个名词＝“和”。
- 「もっと＋形容词＋の」：更……的（东西）。文中例句：もっと安いの、ありませんか。说明：の 代替前面提到的名词（電子辞書）；ありませんか 是否定疑问，表委婉请求。
