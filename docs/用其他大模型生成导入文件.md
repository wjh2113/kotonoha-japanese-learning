# 用其他大模型生成导入文件

把**课堂录音转写**、**笔记截图**（单词 / 语法 / 课文）、课本 PDF/照片发给 ChatGPT、Claude、Kimi 等，让它整理成应用能吃的格式，再在**电脑浏览器**导入。手机 App 只能练习，不能上传。

生产地址：https://japan.aidigitcloud.cn

一课 = **一套完整内容**（课文 + 单词 + 语法），课时名统一（例如第011课）。

**交付要求（必做）：同时给出**

1. **一个完整 Markdown**（`第011课.md`）——导入时**只上传这个 .md** 即可  
2. **一个 ZIP 备份包**（`第011课.zip`）——便于存档或分发给他人；应用导入以 md 为准

导入后对应关系：

| 你的材料 | 进系统哪里 |
| --- | --- |
| 录音转写里的对话 / 课文 + 课文笔记截图 | 「课文」页该课时（朗读、精听、跟读） |
| 单词笔记截图 / 板书生词 | 同名词库单元「第011课」（学习、测验、听写） |
| 语法笔记截图 / 老师讲解要点 | 「语法」页同课号（讲解 + 测验） |

目标：**导入后可直接学**。应用**不会**自动补「记忆技巧 / 同义词 / 形近词 / 发音注意事项」，这些必须写进 md。

---

## 推荐工作流（录音转写 + 笔记截图）

按**一课**整理，不要把多课混进同一个包。

### 1. 先备齐这一课的原料

```
第011课-原料/
  录音转写.txt
  笔记-课文-1.jpg
  笔记-单词-1.jpg
  笔记-语法-1.jpg
  （可选）课本扫描.pdf
```

### 2. 丢给大模型

一次只处理**一课**。转写 + 截图 + 下面整段提示词一起发。

冲突时：**以笔记截图为准**；笔记/转写缺的字段，允许模型用**权威词典与规范知识**补全（见提示词），但不得编造课堂原文。

### 3. 模型必须交两份

- `第011课.md`（课文 + 【单词】+ 【语法课】全在一起）→ **导入用这个**  
- `第011课.zip`（内含同一份 md，或 课文.md + 单词表 + 语法.md，内容与 md 一致、不丢字段）→ **备份用**

### 4. 导入本工具

1. 电脑打开 https://japan.aidigitcloud.cn  
2. 「课文」→「导入课时」→ 选/新建课本 → 课时填「第011课」  
3. **上传 `.md`**（不必上传 zip）  
4. 检查：课文能朗读、单词单元「第011课」、语法页有同课

## 复制给其他模型的提示词

把下面整段，连同**本课录音转写文本**和**笔记截图**一起发给模型。

```
我有这一课的：①课堂录音转写文字；②笔记截图（可能含单词、语法、课文）；③可选课本页。
请整理成「言の葉 / Kotonoha」一课完整课程包。不要写空话解释；按交付清单输出。

【交付（两项都要，缺一不可）】
1) 一份完整 Markdown 文件：第XXX课.md
   （课文 + 【单词】+ 【语法课】写在同一文件；导入应用时只认这个 md）
2) 一个 ZIP 压缩包：第XXX课.zip
   （备份用。包内至少放入与上面内容一致的完整 md；也可再拆 课文.md / 单词.xlsx或单词.md / 语法.md，但信息必须与完整 md 完全一致、不能少字段）
两项内容必须对齐，禁止 md 有、zip 缺或反过来。

【材料用法】
- 对话/课文原文：优先转写里的课堂范句与对话；与笔记冲突时以笔记截图为准。课堂原句不得改写成「更通顺」的别的句子。
- 单词：以单词笔记为主；转写里老师强调的生词也要收录。
- 语法：以语法笔记为主；转写里的注意点、对比、易错读写进「⚠️ 注意」和测验解析。
- 中文解释：优先笔记；笔记没有再用转写语境补全。
- 看不清的原文标【看不清】；真正无法确认的读音标【待确认】。

【补全规则——单词列尽量写满】
表头 12 列必须齐全，每一行尽量填满，禁止大片留空或写「略」「无」「同上」：
序号 | 单词 | 假名 | 词性 | 中文释义 | 罗马音 | 例句 | 例句译文 | 发音注意事项 | 记忆技巧 | 同义词 | 形近词

当笔记/转写缺假名、词性、罗马音、常见义项、同义词、形近词、标准例句时：
- 允许使用你的日语知识库，并尽量检索/对照权威来源补全（如 Weblio、goo辞書、NHK アクセント、教科書・JLPT 常用释义、标准假名与罗马字）。
- 补全内容必须是「官方/通行、准确正宗」的日语信息：标准读音、常用词性、通行中文释义、自然例句。
- 例句优先用本课原文；本课没有时再造初学者能懂的短句，语法必须正确。
- 同义词/形近词：写真实日语词；确实几乎没有近义时该格可空，但假名、词性、释义、罗马音、例句、例句译文、发音注意、记忆技巧不得空。
- 补全不得篡改课堂对话原文；不得用错误读音或罕用义冒充常用义。

【总目标】
导入后能直接学习。宁可多写可靠内容，也不要留空关键列。

【硬性规则】
1) 日语原文保持课堂/课本原句。
2) 「假名注音」列：整句按朗读写。每个汉字都写成 漢字（ひらがな），包括说话人名字、地名、校名。
   正确：山田（やまだ）：スミスさん、今度（こんど）の日曜日（にちようび）、上野（うえの）へ行（い）きませんか。
   错误：山田：スミスさん……（名字没注音）
3) 片假名专有名词（スミス、リン、メニュー）保持片假名。
4) 对话一行一句，说话人用「山田：」格式，和原文同一列。
5) 课号处处一致，例如第011课（文件名、标题、【单词】、【语法课】相同）。

【课文】
- 本课对话/短文收全；多段用 ## 课文1、## 课文2…
- 表头必须是：原文 | 假名注音 | 中文解释
- 每章末尾 **语法考点**：句型：课文例句——中文说明（用法/读音/易错点）

【语法】
- ## 第 N 部分 + ## ① ## ② …
- 每点含：**句型公式**、**例句**（≥2，日语 —— 中文）、**⚠️ 注意**
- ### 测验（建议 5 题，至少 3 题）四选一 + | 题号 | 答案 | 解析 |

【完整 md 结构】
# 【课文整理】第XXX课
## 课文1：…
| 原文 | 假名注音 | 中文解释 |
## 【单词】第XXX课
| 序号 | 单词 | 假名 | 词性 | 中文释义 | 罗马音 | 例句 | 例句译文 | 发音注意事项 | 记忆技巧 | 同义词 | 形近词 |
## 【语法课】第XXX课 …
## 第 1 部分　…
## ① …
### 测验（5题）

【最后一步——专业日语老师自检（必须做，并输出自检报告）】
生成 md 与 zip 之后，请你切换为「有经验的日语教师 / 教材审校」角色，对全文做一轮独立审校，再交终稿。审校至少覆盖：
1) 原文是否与课堂/笔记一致，有无擅自改写；
2) 假名注音：每个汉字是否都有读音；长音/促音/拗音/助词はへを读法是否正确；
3) 单词：假名、词性、罗马音、中文释义是否标准；例句语法是否正确；有无用错近义/形近；
4) 语法：句型公式是否规范；注意点是否准确；测验题干/选项/答案/解析是否一致且无科学性错误；
5) 课号、章节结构、12 列单词表是否齐全。

输出顺序：
① 终稿完整 Markdown（可直接存为 第XXX课.md）
② ZIP 包内容清单 + 各文件全文（或明确可下载的 zip；若平台不能真打包，则给出包内每个文件的完整正文，便于我本地压成 zip）
③ 「日语老师自检报告」：列出已核对项；若有修正，写明改了什么、为什么；若发现无法确认处，列出【待确认】清单（不得假装已确认）。
自检未通过前，不要宣称完成。
```

仓库模版：`public/templates/课文导入模版.md`。单词 Excel：`public/templates/词汇导入模版.xlsx`。

## 生成之后怎么导入

必须用电脑打开 https://japan.aidigitcloud.cn 。

1. 保存模型给出的 **`第XXX课.md`**，并保留 zip 备份。  
2. 看一眼自检报告和【待确认】；有明显错误先让模型改。  
3. 「课文」→「导入课时」→ 课本 + 课时「第011课」→ **只上传 `.md`**。  
4. 词库单元名与课时相同；语法出现在「语法」页。

---

## 导入后在手机上用

数据在服务器。手机 App 联网拉取即可。

朗读依赖「假名注音」里的 `漢字（读音）`。发现问题改 md 后，在电脑上重新上传该课。
