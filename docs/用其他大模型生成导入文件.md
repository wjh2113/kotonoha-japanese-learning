# 用其他大模型生成导入文件

把课本 PDF、照片和笔记截图发给 ChatGPT、Claude、Kimi 等任意模型，让它按本应用格式产出文件，再在**电脑浏览器**导入。手机 App 只能练习，不能上传。

生产地址：https://japan.aidigitcloud.cn

一课对应 **一套完整内容**（课文 + 单词 + 语法），课时名称统一（例如第011课）。交付形态可以是：

1. **一个 Markdown**（推荐简单场景）
2. **一个 ZIP 压缩包**（推荐内容多、单词用 Excel 时）——包内可分多个文件，但**信息必须齐全，不能丢字段、不能省略章节**

导入后：

- 课文出现在「课文」页该课时下
- 单词写入同名词库单元（第011课）
- 语法课写入「语法」页，课号与课时数字一致

目标：**导入后可直接学**。本应用**不会**自动补「记忆技巧 / 同义词 / 形近词 / 发音注意事项」等可选列。

---

## ZIP 包怎么组织（信息不能丢）

包名示例：`第011课.zip`。包内任选一种结构，**三块内容都要有**：

```
第011课/
  课文.md          ← 必有：原文 / 假名注音 / 中文解释 + 语法考点
  单词.xlsx        ← 推荐：12 列表头的词汇手册（也可用 单词.md）
  语法.md          ← 必有：句型公式、例句、注意、测验与答案表
```

也可以：

- 只有一个 `课时.md`（课文+【单词】+【语法课】全写在一起）再打成 zip
- `课文.md` 里已含【单词】【语法课】，zip 里不再重复；若另附 `单词.xlsx`，以表格里写全的为准

文件名尽量带「课文 / 单词 / 语法」字样，方便识别。不要只交对话原文却丢掉单词表或测验。

## 复制给其他模型的提示词

把下面整段连同课本/笔记一起发给模型。

```
请根据我上传的日语课本和笔记截图，生成「言の葉 / Kotonoha」一课的完整导入内容。
不要解释过程。可以输出：
A) 一个完整 Markdown；或
B) 多个文件，并说明打成一个 ZIP（推荐：课文.md + 单词.xlsx 或 单词.md + 语法.md）。
无论 A 还是 B，课文、单词、语法三类信息都必须齐全，禁止用「略」「同上」「见截图」省略。

【总目标】
导入后要能直接学习，尽量不需要我再在应用里手工补内容。
宁可多写可靠内容，也不要留空（除非课本/笔记确实没有，且你无法从上下文合理推出）。

【硬性规则】
1) 日语原文保持课本原句，不要翻译成中文再写回去。
2) 「假名注音」列：整句按朗读写。每个汉字都必须写成 漢字（ひらがな），包括说话人名字、地名、校名。
   正确：山田（やまだ）：スミスさん、今度（こんど）の日曜日（にちようび）、上野（うえの）へ行（い）きませんか。
   错误：山田：スミスさん……（名字没注音，朗读会读成中文）
3) 片假名专有名词（スミス、リン、メニュー）保持片假名，不要改成平假名。
4) 对话一行一句，说话人用「山田：」这种格式，和原文同一列。
5) 中文解释按笔记/课本翻译，口语自然、完整（不要只写半句）。
6) 看不清的字标【看不清】；真正不确定的读音标【待确认】，不要瞎编。
7) 课号处处一致：标题、单词、语法都写同一课，例如第011课。
8) 若用 ZIP：包内文件名请含「课文」「单词/词汇」「语法」；不要漏文件。

【课文要求（全面）】
- 课本里本课全部对话/短文都要收录；多段用 ## 课文1、## 课文2… 拆开，标题写清场景。
- 表格列名必须是：原文 | 假名注音 | 中文解释
- 每章末尾必须有 **语法考点** 列表：每条「句型：课文例句——中文说明（用法/读音/易错点）」。
- 假名注音必须可直接朗读：长音、促音、浊音写对。

【单词要求（全面，宁多勿漏）】
- 收录本课生词表全部词条；课文里出现、生词表没有但明显是生词的也补上。
- 表头 12 列必须齐全：
  序号 | 单词 | 假名 | 词性 | 中文释义 | 罗马音 | 例句 | 例句译文 | 发音注意事项 | 记忆技巧 | 同义词 | 形近词
- 每一行尽量填满（例句优先用本课原句；记忆技巧、发音注意少留空；同义词/形近词没有可空，不要写“无”）。
- 单独文件时：Excel（.xlsx）或 Markdown 表均可；Markdown 时标题用 ## 【单词】第XXX课。

【语法课要求（全面）】
- 本课语法点尽量写全；按「## 第 N 部分」分组，每个语法点用「## ①」「## ②」…
- 每个语法点必须包含：**句型公式**、**例句**（至少 2 条：日语 —— 中文）、**⚠️ 注意**
- 每个部分末尾：### 测验（建议 5 题，至少 3 题）四选一 + 答案表 | 题号 | 答案 | 解析 |
- 单独文件时文件名含「语法」，正文可从 # 标题起笔（不必再写【语法课】，导入时会合并）。

【单文件 Markdown 结构（选 A 时）】
# 【课文整理】第XXX课
## 课文1：…
| 原文 | 假名注音 | 中文解释 |
## 【单词】第XXX课
| 序号 | 单词 | 假名 | … |
## 【语法课】第XXX课 …
## 第 1 部分　…
## ① …
### 测验（5题）

【ZIP 结构（选 B 时）】
第XXX课/
  课文.md
  单词.xlsx   （或 单词.md）
  语法.md

生成前自检：
□ 对话/短文是否齐全，假名注音无漏汉字？
□ 生词 12 列是否尽量填满？
□ 语法是否有公式/例句/注意/带解析的测验？
□ 若是 ZIP，三个文件是否都在、课号是否一致？
```

仓库模版：`public/templates/课文导入模版.md`（对照字段）。单词 Excel 模版：`public/templates/词汇导入模版.xlsx`。

## 生成之后怎么导入

必须用电脑打开 https://japan.aidigitcloud.cn 。

1. 得到 `.md`，或把多个文件打成 `.zip`（不要只交残缺对话）。
2. 快速扫一眼：假名、单词十二列、语法测验答案表是否齐全；缺太多就让模型补全再导。
3. 左侧「课文」→「导入课时」→ 选课本 → 课时填「第011课」（可空）→ 上传 `.md` 或 `.zip`。
4. 系统会合并 zip 内文件并一次入库；词库单元名与课时相同。

---

## 导入后在手机上用

课文、单词、语法存在服务器。手机 App 联网后会拉取，不必在手机上再传文件。

朗读依赖「假名注音」里的 `漢字（读音）`。发现问题就改文件后在电脑上重新上传该课。
