# 用其他大模型生成导入文件

把课本 PDF、照片和笔记截图发给 ChatGPT、Claude、Kimi 等任意模型，让它按本应用格式产出文件，再在**电脑浏览器**导入。手机 App 只能练习，不能上传。

生产地址：https://japan.aidigitcloud.cn

---

## 复制给其他模型的提示词

把下面整段连同课本/笔记一起发给模型。

```
请根据我上传的日语课本和笔记截图，生成「言の葉 / Kotonoha」导入文件。只输出可保存的文件内容，不要解释。

规则（必须遵守）：
1) 日语原文保持课本原句，不要翻译成中文再写回去。
2) 「假名注音」列：整句按朗读写。每个汉字都必须写成 漢字（ひらがな），包括说话人名字。
   正确：山田（やまだ）：スミスさん、今度（こんど）の日曜日（にちようび）、上野（うえの）へ行（い）きませんか。
   错误：山田：スミスさん……（名字没注音，朗读会读成中文）
3) 片假名专有名词（スミス、リン）保持片假名，不要改成平假名。
4) 对话一行一句，说话人用「山田：」这种格式，和原文同一列。
5) 中文解释按笔记/课本翻译，口语自然即可。
6) 语法考点用笔记里的要点，写成短列表，不要长作文。
7) 看不清的字标【看不清】，不要编造。

请生成 **一个** Markdown 文件（课文 + 语法课可写在同一篇），单词另做表格。

文件A 课文+语法.md（必做）

「**语法考点**」会挂在课文阅读页；系统语法讲解写在文末【语法课】。

序号,单词,假名,词性,中文释义,罗马音,例句,例句译文,发音注意事项,记忆技巧,同义词,形近词
```

## 生成之后怎么导入

必须用电脑打开 https://japan.aidigitcloud.cn 。

### 课文

1. 把文件 A 存成 UTF-8 的 `.md`，例如 `第011课.md`。
2. 左侧进入「课文」。
3. 点「添加课文」：
   - 课本：没有就「新建课本」，例如「羊驼日语」；
   - 课时：填「第011课」（可与手册 `#` 标题一致）。
4. 上传该 `.md`。若文末有 `## 【语法课】`，课文章节和语法课会一次入库。
5. 章节按 `## 课文1`、`## 课文2` 自动拆开；语法出现在「语法」页。

### 单词

1. 用 Excel 打开文件 B，另存为 `.xlsx`。不要只丢 CSV / Word。
2. 更稳妥：在「单词学习」点导入 →「下载导入模版」，把模型生成的各列粘进模版再上传。
3. 表头必须含：序号、单词、假名、中文释义、罗马音、例句。词性、例句译文、发音注意、记忆技巧、同义词、形近词可空。
4. 选好目标单元后导入。空着的记忆技巧等列不会用 AI 乱补。

### 语法（已写在课文文件末尾则不必再传）

单独文件时：保存为 `.md`，进入「语法」页上传。需含「第 N 部分」或「① 语法点」以及测验。

---

## 导入后在手机上用

课文、单词、语法存在服务器。手机安装的 App 联网后会拉取，不必在手机上再传一遍文件。

朗读依赖「假名注音」里的 `漢字（读音）`。说话人、地名漏注，仍可能被读成中文。发现问题就改 `.md` 后在电脑上重新上传该课。
