# 用其他大模型生成导入文件

把**课堂录音转写**、**笔记截图**（单词 / 语法 / 课文）、课本 PDF/照片发给 ChatGPT、Claude、Kimi 等，让它整理成应用能吃的格式，再在**电脑浏览器**导入。手机 App 只能练习，不能上传。

生产地址：https://japan.aidigitcloud.cn

一课 = **一套完整内容**（课文 + 单词 + 语法），课时名统一（例如第011课）。交付可以是单个 `.md`，或 `.zip`（包内分文件，信息不能丢）。

导入后对应关系：

| 你的材料 | 进系统哪里 |
| --- | --- |
| 录音转写里的对话 / 课文 + 课文笔记截图 | 「课文」页该课时（朗读、精听、跟读） |
| 单词笔记截图 / 板书生词 | 同名词库单元「第011课」（学习、测验、听写） |
| 语法笔记截图 / 老师讲解要点 | 「语法」页同课号（讲解 + 测验） |

目标：**导入后可直接学**。应用**不会**自动补「记忆技巧 / 同义词 / 形近词 / 发音注意事项」。

---

## 推荐工作流（录音转写 + 笔记截图）

按**一课**整理，不要把多课混进同一个包。

### 1. 先备齐这一课的原料

建议建文件夹 `第011课-原料/`：

```
第011课-原料/
  录音转写.txt          ← 课堂录音转成的文字（可含老师讲解、板书口述）
  笔记-课文-1.jpg       ← 课文/会话相关截图
  笔记-单词-1.jpg       ← 生词表、板书单词
  笔记-语法-1.jpg       ← 句型、注意点、练习
  （可选）课本扫描.pdf
```

转写不用很干净：口语、重复、中日夹杂都可以。截图尽量清晰，同一页多拍一张也行。

### 2. 丢给大模型时怎么说

一次只处理**一课**。把转写文本 + 该课相关截图一起发，再贴下面「复制给其他模型的提示词」。

材料怎么对应整理：

| 原料 | 模型应产出 |
| --- | --- |
| 录音转写里的对话/范句 + 课文笔记 | `课文.md`：原文｜假名注音｜中文解释 + **语法考点** |
| 单词笔记 / 转写里强调的生词 | `单词.xlsx` 或单词表：12 列尽量填满 |
| 语法笔记 / 老师口头讲的句型 | `语法.md`：公式、例句、注意、测验 |

冲突时：**以笔记截图为准**；转写用来补对话原文、例句和老师强调的易错点。看不清标【看不清】，不要编造。

### 3. 模型交什么文件

任选其一：

- **A.** 一个 `第011课.md`（课文 + 【单词】+ 【语法课】全在一起）
- **B.** `第011课.zip`，例如：

```
第011课/
  课文.md
  单词.xlsx    （或 单词.md）
  语法.md
```

信息必须齐全：不要只有对话没有单词表，也不要语法没有测验答案表。

### 4. 导入本工具

1. 电脑打开 https://japan.aidigitcloud.cn  
2. 「课文」→「导入课时」→ 选/新建课本 → 课时填「第011课」  
3. 上传 `.md` 或 `.zip`  
4. 检查：课文能朗读、单词单元出现「第011课」、语法页有同课  

手机联网后会同步，无需在手机再传。

### 5. 和系统功能怎么对上

- **课文朗读 / 精听 / 跟读**：吃「假名注音」列；汉字必须写成 `漢字（ひらがな）`，否则可能读成中文。  
- **单词学习 / 测验 / 听写**：吃单词表；例句、记忆技巧等要模型写进文件，应用内不会补可选列。  
- **语法学习 / 测验**：吃【语法课】或 zip 里的 `语法.md`。  
- **课时统一**：课文课时名、词库单元名、语法课号都是「第011课」这类，方便一课一练。

## ZIP 包怎么组织（信息不能丢）

包名示例：`第011课.zip`。包内**三块都要有**（可合并进一个 md，不可缺内容）：

```
第011课/
  课文.md          ← 原文 / 假名注音 / 中文解释 + 语法考点
  单词.xlsx        ← 12 列表头词汇手册（也可用 单词.md）
  语法.md          ← 句型公式、例句、注意、测验与答案表
```

文件名尽量带「课文 / 单词 / 语法」。不要只交残缺对话。

## 复制给其他模型的提示词

把下面整段，连同**本课录音转写文本**和**笔记截图**一起发给模型。

```
我有这一课的：①课堂录音转写文字；②笔记截图（可能含单词、语法、课文）；③可选课本页。
请整理成「言の葉 / Kotonoha」可导入的一课内容。不要解释过程。

可以输出：
A) 一个完整 Markdown；或
B) 多个文件并说明打成一个 ZIP（推荐：课文.md + 单词.xlsx 或 单词.md + 语法.md）。
无论 A/B，课文、单词、语法三类都必须齐全，禁止「略」「同上」「见截图」。

【材料用法】
- 对话/课文原文：优先转写里的课堂范句与对话；与笔记冲突时以笔记截图为准。
- 单词：以单词笔记截图为主；转写里老师强调的生词也要收录。
- 语法：以语法笔记为主；转写里老师说的注意点、对比、易错读写进「⚠️ 注意」和测验解析。
- 中文解释：优先笔记；笔记没有再用转写语境补全。
- 看不清标【看不清】；读音不确定标【待确认】，不要瞎编。

【总目标】
导入后能直接学习，尽量不用我再在应用里手工补。
宁可多写可靠内容，也不要留空（除非材料确实没有）。

【硬性规则】
1) 日语原文保持课堂/课本原句，不要翻译成中文再写回去。
2) 「假名注音」列：整句按朗读写。每个汉字都写成 漢字（ひらがな），包括说话人名字、地名、校名。
   正确：山田（やまだ）：スミスさん、今度（こんど）の日曜日（にちようび）、上野（うえの）へ行（い）きませんか。
   错误：山田：スミスさん……（名字没注音，朗读会读成中文）
3) 片假名专有名词（スミス、リン、メニュー）保持片假名。
4) 对话一行一句，说话人用「山田：」格式，和原文同一列。
5) 课号处处一致，例如第011课。
6) 若用 ZIP：文件名含「课文」「单词/词汇」「语法」；不要漏文件。

【课文】
- 本课对话/短文收全；多段用 ## 课文1、## 课文2…
- 表头必须是：原文 | 假名注音 | 中文解释
- 每章末尾 **语法考点**：句型：课文例句——中文说明（用法/读音/易错点）

【单词】表头 12 列齐全，行尽量填满：
序号 | 单词 | 假名 | 词性 | 中文释义 | 罗马音 | 例句 | 例句译文 | 发音注意事项 | 记忆技巧 | 同义词 | 形近词
- 例句优先用本课原句；同义词/形近词没有可空，不要写“无”

【语法】
- ## 第 N 部分 + ## ① ## ② …
- 每点含：**句型公式**、**例句**（≥2，日语 —— 中文）、**⚠️ 注意**
- ### 测验（建议 5 题，至少 3 题）四选一 + | 题号 | 答案 | 解析 |

【单文件结构（选 A）】
# 【课文整理】第XXX课
## 课文1：…
## 【单词】第XXX课
## 【语法课】第XXX课 …

【ZIP（选 B）】
第XXX课/课文.md + 单词.xlsx + 语法.md

自检：假名无漏汉字？单词 12 列尽量满？语法有测验解析？课号一致？
```

仓库模版：`public/templates/课文导入模版.md`。单词 Excel：`public/templates/词汇导入模版.xlsx`。

## 生成之后怎么导入

必须用电脑打开 https://japan.aidigitcloud.cn 。

1. 得到 `.md` 或把多个文件打成 `.zip`。  
2. 扫一眼：假名、单词表、语法答案表是否齐全；缺了让模型补一版再导。  
3. 「课文」→「导入课时」→ 课本 + 课时「第011课」→ 上传。  
4. 词库单元名与课时相同；语法出现在「语法」页。

---

## 导入后在手机上用

数据在服务器。手机 App 联网拉取即可。

朗读依赖「假名注音」里的 `漢字（读音）`。发现问题改文件后，在电脑上重新上传该课。
