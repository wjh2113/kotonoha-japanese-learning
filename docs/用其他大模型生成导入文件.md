# 用其他大模型生成导入文件

把**课堂录音转写**、**笔记截图**（单词 / 语法 / 课文）、课本 PDF/照片发给 ChatGPT、Claude、Kimi 等，让它整理成应用能吃的格式，再在**电脑浏览器**导入。手机 App 只能练习，不能上传。

生产地址：https://japan.aidigitcloud.cn

一课 = **一套完整内容**（课文 + 单词 + 语法），课时名统一（例如第011课）。

**交付要求（必做）：同时给出**

1. **一个完整 Markdown**（`第011课.md`）——导入时**只上传这个 .md** 即可  
2. **一个 ZIP 备份包**（`第011课.zip`）——便于存档或分发给他人；应用导入以 md 为准

导入后对应关系：

| 你的材料 | 进系统哪里 |
| --- | --- |
| 录音转写里的对话 / 课文 + 课文笔记截图 | 「课文」页该课时（朗读、精听、跟读） |
| 单词笔记截图 / 板书生词 | 同名词库单元「第011课」（学习、测验、听写） |
| 语法笔记截图 / 老师讲解要点 | 「语法」页同课号（讲解 + 测验） |

目标：**导入后可直接学**。应用**不会**自动补「记忆技巧 / 同义词 / 形近词 / 发音注意事项」，这些必须写进 md。

---

## 推荐工作流（录音转写 + 笔记截图）

按**一课**整理，不要把多课混进同一个包。

### 1. 先备齐这一课的原料

```
第011课-原料/
  录音转写.txt
  笔记-课文-1.jpg
  笔记-单词-1.jpg
  笔记-语法-1.jpg
  （可选）课本扫描.pdf
```

### 2. 丢给大模型

一次只处理**一课**。转写 + 截图 + 下面整段提示词一起发。

冲突时：**以笔记截图为准**；笔记/转写缺的字段，允许模型用**权威词典与规范知识**补全（见提示词），但不得编造课堂原文。

### 3. 模型必须交两份

- `第011课.md`（课文 + 【单词】+ 【语法课】全在一起）→ **导入用这个**  
- `第011课.zip`（内含同一份 md，或 课文.md + 单词表 + 语法.md，内容与 md 一致、不丢字段）→ **备份用**

### 4. 导入本工具

1. 电脑打开 https://japan.aidigitcloud.cn  
2. 「课文」→「导入课时」→ 选/新建课本 → 课时填「第011课」  
3. **上传 `.md`**（不必上传 zip）  
4. 检查：课文能朗读、单词单元「第011课」、语法页有同课

## 复制给其他模型的提示词

把下面整段，连同**本课录音转写文本**和**笔记截图**一起发给模型。

```
我有这一课的：①课堂录音转写文字；②笔记截图（可能含单词、语法、课文）；③可选课本页。
请整理成「言の葉 / Kotonoha」一课完整课程包。不要写空话解释；按交付清单输出。

【交付（两项都要，缺一不可）】
1) 一份完整 Markdown：第XXX课.md
   （课文 + 【单词】+ 【语法课】同一文件；导入应用时只上传这个 md）
2) 一个 ZIP：第XXX课.zip（备份；内容与 md 完全一致，不能少字段）
两项必须对齐。

【材料用法】
- 课文原文：优先转写对话；与笔记冲突以笔记为准。不得擅自改写课堂原句。
- 单词：以单词笔记为主；转写里强调的生词也要收。
- 语法：以语法笔记为主；老师口头易错点写入「⚠️ 注意」和测验解析。
- 看不清标【看不清】；读音无法确认标【待确认】。

【单词——12 列尽量写满】
表头必须是：
序号 | 单词 | 假名 | 词性 | 中文释义 | 罗马音 | 例句 | 例句译文 | 发音注意事项 | 记忆技巧 | 同义词 | 形近词
笔记缺的假名/词性/罗马音/释义/同义形近/标准例句：可用权威词典知识补全（Weblio、goo辞書、NHK、JLPT 通行释义），必须准确正宗；不得编造课堂原文。同义词/形近词可空，其余关键列不得空。

【课文硬性规则】
1) 表头：原文 | 假名注音 | 中文解释
2) 假名注音：每个汉字写成 漢字（ひらがな），含说话人名字、地名
   正确：山田（やまだ）：……　错误：山田：……
3) 片假名专有名词保持片假名；对话一行一句；说话人用「山田：」
4) 多段用 ## 课文1、## 课文2…；章末 **语法考点** 列表
5) 课号处处一致（文件名、标题、【单词】、【语法课】）

【语法——必须对齐内置课「電気屋で」完整度，禁止薄版】
对照内置课，每个 ## ① 语法点都要有下面整套板块（缺一不可，除非该点确实无变形）：

1. **句型公式**
   - 能对比时必须用 Markdown 表格（列如：谓语类型 | 肯定 | 否定 | 疑问）
   - 禁止只写一行「名Aは名Bです」就结束
2. **变形规则**（有接续/词尾变化时必写；列表）
3. **ます形的含义** 或 **用法要点**（文体/意义/何时用；列表）
4. **例句**（≥3 条，尽量含本课课文句）
5. **⚠️ 注意**（≥2 条易错点；必须用列表，不要写成一大段）
6. ### 测验（建议 5 题，至少 3 题）+ 答案表

【语法格式注意事项——写错就会版式不对 / 缺日语 / 测验 0 题】
A) 部分：## 第 N 部分　标题
B) 语法点：## ① 标题（下一个点 ## ② …）
C) 小节标题必须单独一行加粗，只能用这些（可按内容选用）：
   **句型公式** / **变形规则** / **ます形的含义** / **用法要点** / **例句** / **⚠️ 注意**
D) 例句格式（最容易错！）：
   - 正确：- わたしは 日本人です。—— 我是日本人。
   - 错误：- 我是日本人。（只有中文 → 卡片会缺日语）
   - 错误：- 我是日本人。—— わたしは日本人です。（中日写反）
   - 错误：用冒号、逗号、空格代替 ——
   必须「日语在左 —— 中文在右」，中间用 —— 或 —
E) ### 测验 必须写在「本①内部」、下一个 ## ② 之前；每个①各自一份测验
   禁止整课共用一个测验（否则会出现「开始测验（0）」）
F) 测验题：
   **Q1.** 题干
   - A. …
   - B. …
   - C. …
   - D. …
   紧跟答案表（不要省略解析）：
   | 题号 | 答案 | 解析 |
   | --- | --- | --- |
   | 1 | B | …… |
G) 自检：每个①打开后应能看到公式表/规则/含义/多条例句卡/注意/测验题数>0

【最后——日语老师自检（必须输出报告）】
以教材审校身份核对后交终稿：
1) 课文原句未擅自改写；假名注音无漏汉字
2) 单词 12 列尽量满且读音/词性/释义准确
3) 语法达到内置课完整度：有公式表、变形规则、含义、≥3 条例句（日语在左）、≥2 条注意、每点独立测验且题数>0
4) 无「只有中文的例句卡」、无「测验 0 题」、无中日例句写反
5) 课号三处一致

输出顺序：

② ZIP 清单+各文件全文（平台不能打包时给出可本地压缩的全文）
③ 「日语老师自检报告」：已核对项 / 修正说明 / 【待确认】清单
自检未通过前不要宣称完成。
```

仓库模版：`public/templates/课文导入模版.md`。单词 Excel：`public/templates/词汇导入模版.xlsx`。

## 生成之后怎么导入

必须用电脑打开 https://japan.aidigitcloud.cn 。

1. 保存模型给出的 **`第XXX课.md`**，并保留 zip 备份。  
2. 看一眼自检报告和【待确认】；有明显错误先让模型改。  
3. 「课文」→「导入课时」→ 课本 + 课时「第011课」→ **只上传 `.md`**。  
4. 词库单元名与课时相同；语法出现在「语法」页。

---

## 导入后在手机上用

数据在服务器。手机 App 联网拉取即可。

朗读依赖「假名注音」里的 `漢字（读音）`。发现问题改 md 后，在电脑上重新上传该课。
